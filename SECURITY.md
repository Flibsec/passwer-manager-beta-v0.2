# ⚠️ Предупреждение о безопасности

Это БЕТА-проект с намеренно слабым шифрованием для целей тестирования.
Алгоритмы шифрования открыты и доступны в коде НАМЕРЕННО:
  - Это позволяет находить ошибки
  - Открытый код алгоритма шифрования = лучше для обновлений
  - Возможность предлогать улучшения

## Текущие алгоритмы:

### Шифрование ключа
  - Простая подстановочная замена (пример: a = "&$8724'>34#7;5", b = "7[23^$@4':.9,/")
  - Крайне уязвим

### Шифрование пароля:
  - Маленькая математическая операция с паролем
  - Преобразование пароля в hex (шестнадцатеричное) число
  - Добавление в конец "липовой" части зашифрованного пароля
  - На самом деле не использует серьёзное шифрование

## ❌ НЕ ДЕЛАЙ:
  - Не сохраняй реальные пароли
  - Не используй в production
  - Не доверяй шифрованию для конфидециальных данных

## ✅ ДЕЛАЙ:
  - Используй только для тестирования
  - Сообщай об ошибках безопасности
  - Предлогай улучшения
