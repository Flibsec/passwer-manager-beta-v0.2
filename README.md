# passwer-manager-beta-v0.1
⚠️**БЕТА-ВЕРСИЯ - ТОЛЬКО ДЛЯ ТЕСТИРОВАНИЯ. ШИФРОВАНИЕ СЛАБОЕ И НЕПОЛНОЕ. НЕ ИСПОЛЬЗОВАТЬ для хранения реальных паролей и конфидециальных данных. Только для тестирования и исправления ошибок.
Менеджер паролей с шифрованием (для обучения и тестирования).

## ⚠️ КРИТИЧЕСКОЕ ПРЕДУПРЕЖДЕНИЕ

**НЕ ИСПОЛЬЗУЙ ЭТО ДЛЯ РЕАЛЬНЫХ ПАРОЛЕЙ!**

- Шифрование **СЛАБОЕ** и **НЕПОЛНОЕ**
- Алгоритмы намеренно простые для целей обучения
- Пока **НЕ ПОДХОДИТ** для production-использования
- Используй **ТОЛЬКО** для тестирования и разработки

Подробнее о проблемах безопасности -> [SECURITY.md](SECURITY.md)

---

## Возможности:
  - ✅ Создание новых ключей для шифрования
  - ✅ Сохранение паролей в зашифрованном виде
  - ✅ Загрузка паролей из файла
  - ✅ Простое шифрование
  - ✅ Умное управление файлами с паролем и с ключём (если файла нет, программа создаст его но сбросится пароль и ключ созданный вами)

## Текущие ограничения:
  - ❌ Слабое шифрование
  - ❌ Нет защиты от frequency analysis
  - ❌ Простая математика для пароля (легко взломать)
  - ❌ Нет сохранения ключей в безопасном виде

## Установка
  - Готовый бинарный файл: (https://github.com/Flibsec/passwer-manager-beta-v0.1/releases)
  - Ручная установка:
git clone https://github.com/Flibsec/passwer-manager-beta-v0.1.git
cd passwer-manager-beta-v0.1
cargo build --release

## Требования (для ручной установки):
  - Rust 1.70+
  - Cargo
