# passwer-manager-beta-v0.1
⚠️**БЕТА-ВЕРСИЯ - ТОЛЬКО ДЛЯ ТЕСТИРОВАНИЯ. ШИФРОВАНИЕ СЛАБОЕ И НЕПОЛНОЕ. НЕ ИСПОЛЬЗОВАТЬ для хранения реальных паролей и конфидециальных данных. Только для тестирования и исправления ошибок.
Менеджер паролей с шифрованием (для обучения и тестирования).

## ⚠️ КРИТИЧЕСКОЕ ПРЕДУПРЕЖДЕНИЕ

**НЕ ИСПОЛЬЗУЙ ЭТО ДЛЯ РЕАЛЬНЫХ ПАРОЛЕЙ!**

- Шифрование **СЛАБОЕ** и **НЕПОЛНОЕ**
- Алгоритмы намеренно простые для целей обучения
- Пока **НЕ ПОДХОДИТ** для production-использования
- Используй **ТОЛЬКО** для тестирования и разработки

Подробнее о проблемах безопасности -> [SECURITY.md](SECURITY.md)

---

## В НОВОЙ ВЕРСИИ (0.2) ДОБАВЛЕНО:
  - ✅ Умное управление паролем (если файл с зашифрованным паролем повредится то пароль сбросится при запуске программы)
  - ✅ **НЕМНОГО** улучшенное шифрование ключа и пароля (добавление фейковых значений в файл с зашифрованным паролем или ключём, фейковые значения не читаются программой при расшифровке)
  - ✅ Добавление в конец зашифрованного ключа фейковой строки (принцип как у пароля), (при расшифровке фейковая строка не читается программой)
  - ✅ Создание ключа по умолчанию (root)

## ПЛАНЫ ДЛЯ СЛЕДУЮЩИХ ОБНОВЛЕНИЙ: 
  - **НАСТОЯЩИЙ** метод шифрования (будет доступно с версии релиза 1.0), это не касается beta версий 0.1...-0.9...
  - Защита ключа и пароля в зашифрованном виде
  - Улучшение шифрования
  - Выбор шифрования (слабый, средний, сильный, максимальный) по сравнению текущий метод шифрования **слабый**, каждый метод будет лучше предыдущего в 2-3 раза
  - Больше идей пока нет:)

## Возможности:
  - ✅ Создание новых ключей для шифрования
  - ✅ Сохранение паролей в зашифрованном виде
  - ✅ Загрузка паролей из файла
  - ✅ Простое шифрование
  - ✅ Умное управление файлами с паролем и с ключём (если файла нет, программа создаст его но сбросится пароль и ключ созданный вами)
  - ✅ Умное управление паролем (если файл с зашифрованным паролем повредится то пароль сбросится при запуске программы)

## Текущие ограничения:
  - ❌ Слабое шифрование
  - ❌ Нет защиты от frequency analysis
  - ❌ Простая математика для пароля (легко взломать)
  - ❌ Нет сохранения ключей в безопасном виде
